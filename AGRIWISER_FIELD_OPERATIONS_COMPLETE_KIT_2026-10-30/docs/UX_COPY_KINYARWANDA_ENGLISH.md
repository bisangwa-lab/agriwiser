# Plain-language UX wording — labels are changeable

| Meaning | Suggested English | Suggested Kinyarwanda |
|---|---|---|
| Overview | What needs attention? | Ni iki gikeneye kwitabwaho? |
| Assignment | My assigned work | Imirimo nshinzwe |
| Review signal | Finding to verify | Ikigomba kugenzurwa |
| Evidence backlog | Evidence still needed | Ibimenyetso bikenewe |
| Due soon | Due in seven days | Ibizarenza igihe mu minsi irindwi |
| Overdue | Past due | Ibyarengeje igihe |
| Find source | View original source | Reba inkomoko y'amakuru |
| Create case | Start investigation | Tangiza iperereza |
| Observation | Record what you observed | Andika ibyo wabonye |
| Supervisor | Submit for review | Ohereza gusuzumwa |
| Returned | Needs corrections | Bisaba gukosorwa |
| Approved | Reviewed and approved | Byasuzumwe byemezwa |
| Missing | Not available | Nta makuru ahari |
| Model estimate | Model-based estimate | Ikigereranyo cya model |

Never display 'disaster confirmed', 'crop failure caused by weather', 'official NISR warning', or '100% production collapse' unless explicitly grounded by appropriately qualified source evidence. Keep tooltips on indicator definitions and quality badges.
