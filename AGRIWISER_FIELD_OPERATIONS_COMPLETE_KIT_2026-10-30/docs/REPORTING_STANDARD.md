# Investigation and field report standard

1. **Cover:** organization/product, report title, district, crop, season/year, investigation ID, version, generated on, author, reviewer, classification.
2. **Decision summary:** exactly what triggered review; whether confirmed, inconclusive or data issue; recommended follow-ups. No unsupported causal claims.
3. **Question and scope:** trigger, indicator definition, geography/period coverage, selected crop and investigation questions.
4. **Source evidence:** table with original NISR source(s), worksheet/table/page references where known, current/baseline values and units, source statuses, revision dates, source links.
5. **Methods and calculations:** formulas and explicit exclusion/reconciliation rules; quality flags; explain non-comparable periods and unsupported percentages.
6. **Fieldwork:** authorized visit dates, methods, evidence history, field observations, limitations and assignee.
7. **Climate context (optional):** source/provider, unit, grid resolution, coverage, temporal alignment and caveat; never as direct farm measurement or proof of cause.
8. **Findings:** triangulated observations, conflicting evidence, uncertainties, unresolved questions.
9. **Outcome and oversight:** reviewer decision and reason, documented approvals/returns, current status.
10. **Actions:** recommendations, owner, due date, verification/closure criteria, action progress.
11. **Appendices:** metadata dictionary, record IDs, audit references, omitted/restricted data statement and export timestamp.

## Export formats
HTML / printable PDF first; CSV for tabular data, Excel workbook only where all underlying tables and charts correctly reflect source facts; include metadata sheet and 'not available' notes. Respect role permissions and report redaction. No chart screenshot without source-data linkage and chart alt description.
